OFFICIAL LEGAL DOCUMENTATION

Privacy Policy — Pizza Converter

Last updated: October 30, 2026 • Effective Date: October 30, 2026

This Privacy Policy applies to the desktop software application Pizza Converter ("the Application", "Software", or "Service"), engineered and provided by Ken Dao / NEEFLOW ("Developer", "we", "us", or "our"). This document sets forth our comprehensive data protection commitments pursuant to the General Data Protection Regulation (Regulation (EU) 2016/679, "GDPR"), the UK Data Protection Act 2018 / UK GDPR, the California Consumer Privacy Act as amended by the California Privacy Rights Act ("CCPA/CPRA"), Canada's Personal Information Protection and Electronic Documents Act ("PIPEDA"), Brazil's Lei Geral de Proteção de Dados ("LGPD"), and the United States Children's Online Privacy Protection Act ("COPPA").

1. Fundamental Zero-Data-Collection Principle

Pizza Converter is engineered from its inception with a zero-knowledge, zero-telemetry architecture. In normal day-to-day operations, the Application collects, transmits, stores, aggregates, sells, or shares ZERO bytes of personal data. Specifically:

  • No Identifiers: We do not collect names, email addresses, phone numbers, postal addresses, or user account credentials.
  • No Content Telemetry: We do not log, inspect, transmit, or retain file names, file contents, file extensions, folder paths, document text, or converted outputs.
  • No Behavioral Tracking: The Application embeds zero advertising SDKs, zero user tracking beacons, zero heatmaps, and zero commercial analytics frameworks (such as Google Analytics, Firebase, Mixpanel, or Segment).
  • No Remote Processing: All audio, video, image, document, and structural conversions execute 100% locally on your machine. We operate no cloud conversion relays, hosted processing queues, or web proxy intermediaries.

2. 100% On-Device Processing & Memory Containment

When you select files for conversion, Pizza Converter streams the source file data directly into volatile device memory (RAM), executes transformation routines utilizing local multi-threaded CPU instructions and native SIMD hardware acceleration (AVX2, SSE4.2, NEON), and writes the converted output directly to your designated destination directory. Upon task completion, volatile working buffers are immediately wiped and released to the operating system. No cached file fragments or temporary working files are uploaded to any remote network endpoint.

3. Operating System Capabilities & File Permissions

Pizza Converter requires specific operating system permissions solely to deliver user-directed file utilities:

  • Broad File System Access: Read and write permissions are used solely to open the specific files you select for conversion and to write output files to your chosen destination directory. The Software never indexes, inventories, traverses, or scans your file system in the background.
  • Global Keyboard Input Hook: A low-level keyboard hook is utilized solely to detect user-configured hotkey triggers (default: Ctrl + G, Alt + G, or custom key combinations) to display the radial wheel menu at cursor coordinates. Non-trigger keystrokes are passed through immediately without inspection, logging, or caching. Keystrokes are never recorded or stored.
  • Cursor Position API: The Application inspects cursor coordinates exclusively to place the radial converter wheel directly under your pointer when activated.

4. Pro Licensing, Machine Fingerprinting, & Anti-Tamper Security Telemetry Exception

In standard use, Pizza Converter initiates zero network requests. The sole exceptions are strictly confined to security enforcement and license verification:

  • License Key Redemption: When you redeem a Pro license key or voucher, the Application contacts our secure licensing endpoint (https://pizza-license-server.ngmrmyd55h.workers.dev/api/redeem), transmitting only the provided license key and a one-way, irreversible SHA-256 cryptographic hardware hash (derived from system board and machine GUID) to bind the activation to your authorized device seat. No personal identity or personal file data is attached.
  • Anti-Tamper & Security Breach Reporting: In the event that active memory corruption, attached debuggers, code injection, cryptographic key tampering, or binary cracking routines are detected by the internal runtime security monitor, the Application transmits an automated security report (containing the anonymous machine hash, tamper code, and executable timestamp) to our cloud edge worker to revoke compromised licenses and protect intellectual property. This mechanism serves solely to prevent piracy and intellectual property theft.

5. On-Device Artificial Intelligence & Neural Inference

Features utilizing machine learning—such as AI background removal, scan enhancement, and edge binarization—run entirely through localized ONNX model weights compiled for on-device inference. Visual inputs never exit your machine, and weights are never fine-tuned or updated using your personal images.

6. In-App Commerce & Third-Party App Store Transactions

Transactions for Pro upgrades are processed exclusively by official digital store platforms (including the Microsoft Store and Apple App Store) pursuant to their independent commerce policies. NEEFLOW does not collect, process, handle, or store financial credentials, credit card details, billing addresses, or banking information.

7. Local Functional Storage

The Application maintains local functional settings (such as designated output folder, preferred trigger hotkey, active language, and recent conversion history for the Undo buffer) within standard operating system application storage directories. This data is strictly local, never synchronized to remote databases, and may be wiped at any time via the Settings interface.

8. Data Subject Rights (GDPR / CCPA / CPRA Disclosures)

Under the GDPR (Articles 15-22) and the CCPA (Cal. Civ. Code § 1798.100 et seq.), individuals possess statutory rights to access, rectify, delete, and port personal records held by data controllers. Because Pizza Converter maintains zero databases of user identities, collects no personal telemetry, and stores no records connecting individuals to usage data, we maintain no personal data records capable of retrieval, modification, or deletion upon request.

9. Children's Online Privacy Protection Act (COPPA)

Pizza Converter does not knowingly solicit or collect information from children under the age of 13 (or under 16 within relevant EU jurisdictions). Given that zero personal data is collected from any user, our systems fully comply with the statutory requirements of the Children's Online Privacy Protection Act (COPPA).

10. Third-Party Libraries & Runtimes

  • FFmpeg: Bundled under GNU LGPL v2.1. Executed locally as an isolated process to handle audio and video encoding. It establishes no network connections.
  • ONNX Runtime & OpenCV: Embedded under MIT and Apache 2.0 licenses. Executes local array arithmetic and neural evaluation without network activity.
