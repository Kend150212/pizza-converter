1. Product Overview

Pizza Converter (the "Software") is a desktop productivity application for Microsoft Windows and Apple macOS that brings file conversion, document tools, image design utilities, artificial-intelligence-assisted video tools and cloud sharing into a single radial ("pizza") menu that appears directly at the position of your mouse cursor.
